# 🍕 Menú digital

Menú digital accesible mediante código QR para consultar productos y enviar pedidos.

## Cliente
- Escanear un QR y abrir el menú.
- Ver comidas, bebidas, categorías, precios y fotos.
- Buscar y seleccionar productos.
- Armar un pedido, ver el total y enviarlo.

## Negocio
- Agregar y eliminar comidas.
- Cambiar precios y fotos.
- Crear categorías.
- Marcar productos disponibles o no disponibles.
- Cambiar promociones.

**Presupuesto de referencia:** $15.000 aprox.
